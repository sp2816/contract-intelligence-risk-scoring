# AI Contract Intelligence Chatbot

An AI-powered legal assistant that allows users to upload contracts, analyze risks, extract legal entities, detect clauses, and interact with contracts using natural language.

## Tech Stack

Frontend:
- React
- TailwindCSS

Backend:
- FastAPI

Database:
- PostgreSQL

ML/NLP:
- spaCy
- Transformers
- LangChain
- Pinecone

Features:
- Contract Upload
- OCR Processing
- Entity Extraction
- Clause Detection
- Risk Scoring
- Contract Chatbot
